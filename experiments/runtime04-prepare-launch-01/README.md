# Runtime04 preparation launcher: unrun draft

This wrapper is not prepared or executed. A concrete invocation must bind the
successful reader rehearsal, its current input table, the actual independent
21-copy retirement audit, all four compiler prerequisite audits, and (for final
installation preparation) the completed independent source-preflight audit.
It also binds the startup adapter, its exact source manifest and completed
startup/owner controls. The fresh adapter preserves the qualified runtime04
packet location, imports and controller, while explicitly deriving its startup
environment from the observed platform state.
There is no placeholder receipt accepted as success.

The producer owns its existing canonical lock; the wrapper never holds it while
waiting for the producer. Preparation requires 16 GiB free, with the existing
9 GiB live floor. Actual compiler launches keep their separate 24 GiB gate.
The child has a 900-second CPU limit and a 16 MiB per-file limit. Its Python
observation is bounded to 1,800 seconds including lock waiting; the parent stops
observing after 1,850 seconds and reports an unclosed task without signaling it.

Before any producer imports, the wrapper authenticates the complete local Python
source closure in the separately completed rehearsal table and the bounded,
separately reviewed adapter manifest. Overlaps must retain exact current rows;
retired and absent inputs cannot be relabeled. A Python audit hook
rejects undeclared local source execution, subprocesses, network connections,
signals and writes outside the seven fresh proposal files and its own final
observation. This is a guard for reviewed Python, not a security sandbox for
arbitrary native code. Exact passed and observed environments survive a child
failure. Original prepared table membership is not modified by this wrapper.
The parent binds the final child observation digest and records child exit before
reading post-exit outputs. Observation errors cannot produce a passing record.

The saved Popen PID, command, environment and parent observations do not claim
independent process probes. Source review and a concrete invocation review are
required before this draft can run. No runtime or application is qualified here.
