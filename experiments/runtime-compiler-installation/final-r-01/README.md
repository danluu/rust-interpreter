# Native runtime installation R

Prepared, not executed. This installs the admitted E runtime at a fresh final
root and requires the two ordinary source diagnostics before publishing its
immutable `ready.json`. It does not qualify an application, prepare std MIR,
build an exporter, or claim a complete stage2 compiler.

The unchanged metadata03 components contain 3,709 files / 650,879,912 logical
bytes: 64 native runtime files, 3,644 ordinary standard-source files and one
admitted support executable. Source links are handled by the existing runtime
policy; the rustc-dev source link remains omitted. All component bytes and
original metadata are checked before and after copying; the production installer
also hashes the final destination independently before its probes.

The new specification adds only the exact standard-source capability, the
passed E source-preflight receipt hash, this proposal's source-policy proof
hash, and the explicit final-source prepublication policy. The original candidate
is unchanged. `source-policy-proof.json` binds the actual successful native005
build's raw expanded compiler and standard-library commands, the admitted
bootstrap TOML, eight unchanged source-remap implementation files and the
previously reviewed Cargo recipe pin. Its Cargo field names the reviewed source
contract, not a newly observed Cargo executable. It makes no rustc-dev source or
complete-diagnostic claim.

The controller uses 28 ordered child declarations: five Git guards, one xcrun
selection, eleven `/usr/bin/otool -l` inspections at the final root, three final
compiler identity probes, two final source probes, five Git guards and one
xcrun selection. Both xcrun observations must match the admitted SDK link and
resolved executable; its identity and parent route are checked around each
inspector invocation. Every child retains its argv, environment, PID, process
identity and raw outputs through the unchanged owned supervisor.

The existing final-source validator binds E's passed full-guard receipt and
requires raw E0080 local snippets against R's ordinary standard sources. Its
second invocation checks the truthful virtual `/rustc/<commit>/library` identity.
All complete source/input checks and the final SDK selection occur inside the
prepublication callback, before the installer may create a ready record.

Admission takes the canonical benchmark lock with a 600 second wait and
requires a fresh 10 GiB free-space check. The copied payload, per-file block
rounding, retained-input allowance, diagnostic/receipt allowance and metadata
reservation total less than 1 GiB. The unchanged supervisor preserves its 9 GiB
active-child stop and 8 GiB floor. Existing B2 and pthread admission gates are
unchanged. Failure keeps evidence and any partial installation; there is no
cleanup, automatic retry or control of another workload.

`launch.json` is the concrete unexecuted command and sanitized environment;
`inputs.json` freezes its controller, production module closure, supervisor,
Python and evidence. The explicit CoreFoundation text-encoding value prevents
an implicit macOS Python startup environment addition. `source-derivation.py`
is a source-only proposal generator and is not part of the launch command.
