# Completed run-make qualification retention

This evidence-only stage retains the completed and independently audited run-make qualification: one D2 recipe compilation, one unchanged E2 execution, 230 nested command blocks (144 compiler commands, 86 native runs, 39 expected compiler failures), restored fixture, complete final outputs, raw histories, loader proofs, retained source/proof copies, and the complete original 166-file freeze. The three compiler prerequisite histories retain the failed support attempt and all unavailable historical cwd observations. This is native recipe qualification; it makes no application, performance, or hash-driver qualification claim.

`prepare.py` reads and hashes the closed inputs and writes a fresh proposal. `archive.py` requires separate review of that exact proposal before its single execution. It uses canonical admission with a 600-second bound and 9 GiB live floor, zero workload children, at most 1,536 members and 384 MiB logical input, and a capped compressed writer that refuses writes beyond 64 MiB. All bytes and identities are checked before and after retention. Full archive member hashes and gzip EOF/CRC are read back before success. Provider binaries are not copied; their exact admission and loader catalogs remain in the evidence.

The archive and its manifest go to `results/hir-options-hash-run-make-01`. Only after successful execution and independent readback will the publication add the exact launcher/outer/terminal records, independent audit and concise result summary, then commit the experiment sources and result artifacts. Original run-make source, freeze and actual outputs remain unchanged. There is no compiler or recipe rerun, cleanup, automatic retry, or process-control action.

The unrun evidence-01 proposal is preserved byte-for-byte. This successor changes only the retention WORK/supervisor namespace to `.work/run-make-qualification-retention-01`, outside the shared compiler workload prefixes, and retains the six predecessor proposal files. It introduces no new compiler-stage evidence root.
