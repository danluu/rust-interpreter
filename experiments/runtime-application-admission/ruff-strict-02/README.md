Prepared only. No compiler, application or benchmark execution is authorized by this packet itself.

Use the same installed runtime, shared std, published tools, JIT settings, MIR/HIR flags, two Cargo jobs, six unchanged registry test bodies and original → wrong edit → five cumulative edits → restored original sequence as the completed Ruff diagnostic. This is a strict correctness history, not a performance comparison or a new native baseline.

Every ordinary launcher must freshly compile exactly one selected Ruff library-test unit according to actual wrapper argv records. Retain all actual wrapper records, raw supervised launcher output, exact source hashes, selected bytecode/catalog/dep-info and Cargo timing report. Verify both diagnostic environment variables absent from the explicit environment and Cargo configuration, unset in selected compiler dep-info, false in actual launcher stats, and no `.calls.json` diagnostic sidecar. Off/on bytecode must agree for each source state. Comparison with the earlier compatibility-enabled bytecode is descriptive and may differ due to the policy change.

Successful states run all six tests as the original batch. Each wrong-edit batch must fail at a guest assertion; this preserves the original negative contract and does not claim six individually rejected tests. Aggregate Cargo stderr can replay dependency HIR diagnostics, so this history does not attribute its event totals to the newly compiled selected crate or report a global coverage denominator. Wrapper argv records do not establish every nested process ancestry.

The shared runtime/std/tools and restored pinned Ruff source are fully checked before and after under the canonical 600-second lock. Source restoration occurs on failure. All failures are retained without an automatic retry.
