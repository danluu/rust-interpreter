# Saved-result assessor

`assess.py` implements the unchanged `PROTOCOL.md` calculation. It imports only the Python standard library and starts no processes. `assess(ab, aa, candidate_tool_key)` takes two dictionaries containing the ordinary `summary`, raw `records`, and ordinary `verification` documents. The candidate tool key is an explicit argument; no future tool or evidence digest is guessed.

It requires all 24 rows per history: three cold, three wrong-edit, fifteen edited, and three restored-original rows. It reconstructs every field of the five summary pairs from the raw rows, checks the six tests and source states across histories, requires paired RBC digests and the fixed runtime/settings/cache selections, and retains complete-command wall/CPU subtotals and separate build-to-ready ratios.

The decision is exactly `median(AB candidate/baseline) + median(abs(AA candidate/baseline - 1)) < 1`. Equality parks the performance path. Cold, wrong-edit and restoration rows do not enter that formula. No VM execution time is subtracted. Historical std preparation costs retain their historical label.

The pure function's result is a calculation, not a closed-owner qualification. `owner_closures`, `session_totals`, and `actual_input_refs` remain unset, and `qualification_gate_complete` is false. The forthcoming per-history observer adapter must authenticate both successful runner/verifier closures, each independently observed parent closure, exact input digests and the reviewed AB cache retirement before an actual result can authorize advancement. That transport schema is still under preparation. This module does not replace either ordinary verifier or prove cache freshness by itself.

`test_assess.py` contains synthetic counterexamples only. The initial 11 methods passed once, then source review found that the ordinary runner records native `test_threads` as the argument string `"1"`, not integer `1`. The original source and result remain retained. After correcting the fixture and predicate and adding an integer-rejection regression, all 12 methods passed once under `/opt/homebrew/bin/python3 -B -m unittest -v test_assess`. Raw output, source maps and parent/child closures are retained in `results/ruff-options-hash-assessor-tests-01` and `results/ruff-options-hash-assessor-tests-02`. They cover the ratio-of-medians trap, absolute deviations before median, equality, excluded controls, invalid timings/overflow, missing/duplicate rows, summary tampering, source/test/RBC mismatch, verification failure and incompatible settings. They are not fresh Ruff measurements.
