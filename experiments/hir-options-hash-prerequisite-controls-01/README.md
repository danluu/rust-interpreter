Nine bounded pure controls validate the exact command/receipt/raw-byte associations consumed by the future hash-driver stage. All fixtures are in memory. The tests exercise expected error exits, failed-owner rejection, changed bytes, reordered or substituted commands, foreign process identity, overlapping/nonfinite times, and explicit unavailable cwd observations. They do not run a compiler, native executable, benchmark or provider probe. The existing admitted pure-control harness retains canonical exclusion, 16/9/8 GiB admission, a 120-second alarm, 60-second CPU limit, bounded output, and its process/network/signal audit hook. The separate native_controls readback function is source-only until actual native prerequisites exist; these nine controls do not qualify that integration.
