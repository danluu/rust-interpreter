This is an unrun, source-only native Ruff frontend screen for the matched N external proc-macro client. The N driver and its builtin quote implementation remain unchanged. The already passed default-discovery overlay result and independent readback are prerequisites; they are not new Ruff behavioral or performance evidence.

The experiment makes one owned copy of all 11,119 acquired Ruff source entries at revision d136bd8d002a648de5f344df602e492658306f1e. It also copies the original ownership marker as historical provenance and records separate ownership for the new copy. It creates fresh stock and candidate Cargo target directories. The shared offline Cargo registry supplies sources; old compiled target caches are not reused. Cargo runs one job with the repository's test profile and incremental compilation explicitly disabled for both arms from setup onward. Both commands disable automatic cache cleanup. The canonical Ruff source and all existing provider/overlay files are read only.

The capture executable is RUSTC for every Cargo compilation, including host proc macros and build scripts. It appends the exact arm sysroot even to Cargo queries, records received/forwarded argv and environment, retains compiler stdin where used, and preserves inherited jobserver and canonical-lock descriptors. Every actual macro dylib must prove the four matching arm-owned proc_macro/literal artifacts in dep-info; old N, opposite-arm and T Rust libraries are rejected. Cargo remains the pinned installed orchestrator. The same profile and actual normalized compile vectors must agree across arms. No target-only RUSTFLAGS assumption selects host proc macros.

After setup, the captured real ruff_linter --test --emit=dep-info,metadata command is replayed with a fresh output directory. Its source, cfg/check flags and environment are preserved, except for explicitly recorded replacement of stale Cargo jobserver pipe numbers with an empty owned jobs=1 pipe. Original auth/fds tokens must agree within and across all jobserver variables. Pipe endpoints must be live and inheritable before log files open. This transport replacement is not additional compiler concurrency.

Each of six blocks applies the first existing production edit, match-optional-rule-code-explicitly, without changing any test body. Both arms receive an untimed warm call. The block then performs two counterbalanced A/B pairs and one stock A/A pair, rotating the A/A position. It restores the exact original source and performs both restoration checks outside timing. The fixed totals are 36 timed native calls, 12 warm calls, 12 restoration calls and two Cargo setups. The known wrong-production edit is accepted by cargo check and supplies no compile-negative claim here. The six-test behavioral controls, all five edits, holdouts, interpreter workflow and full end-to-end criterion remain later work.

Wall time runs from immediately before native Popen to the timestamp immediately after a blocking wait4 returns. The parent observes a finite deadline independently; timeout polling does not set the measured completion timestamp. Actual wait4 CPU/rusage and all raw output are retained. The interval includes process launch/reap and concurrent parent observer I/O applied equally to both arms. Pre/post verification, source/cache guards, artifact hashing and restoration are outside that interval. Source and dependency identity checks run around every sample; complete input/cache EOF readback follows the fixed sequence. Every replay keeps its full verification separately, and execution.json retains its exact reference and timing. Large source/dependency tables use fixed 1,000-row evidence parts before timing starts.

The precommitted primary statistic is the median of all 12 candidate/stock wall ratios. Same-run noise is the largest absolute departure from one among the six stock-second/stock-first ratios. An attributable screening gain requires 1 minus the median candidate/stock ratio to exceed that noise. Otherwise the allocator performance path is parked with the complete neutral/slower/inconclusive result retained. There is no unchanged retry for better numbers and no sub-0.5-second or full-workflow claim from this screen.

Admission uses the existing canonical lock and 16 GiB free entry / 9 GiB stop / 8 GiB floor policy, with a 4 GiB owned-output limit. Setup allows at most 1,024 observed native calls per arm. Each native observation is finite; no process is signalled. All capture records are inspected even when a wrapper did not publish route.json. Unknown native closure prevents further calls and restoration. Parent lock closure is recorded honestly and is not claimed to release a descriptor still inherited by an unclosed child.

No Cargo capability probe was used to establish this syntax.
