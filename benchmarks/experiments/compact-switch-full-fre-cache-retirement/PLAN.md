# Conditional retirement of completed compact-switch fre compiler caches

Invoke retire.py with exactly token or folded. Each option selects one fixed,
independently closed176-command history and its nine exact compiler namespaces.
This is derived from the already closed full folded retirement implementation;
only case selection, original test count, current controller, endpoint and exact
candidate binding change. No old retirement or timing is repeated.

Admit only below existing24GiB parser/dynamic build headroom, under the shared
benchmark lock and all selected invocation locks. Revalidate original source,
all176 outcomes, strict checks, exact current candidate, finished server/process
receipts, source-bound evidence and every protected hash. Inventory regular
nonexecutable compiler .o/.rlib/.rmeta/incremental files only. Reject open files
and changed inode/device/size/mtime/mode before unlink. Preserve binaries, RBC,
catalogs, source, raw proofs, installed tools, shared build target and all other
workloads. Private and peer data are outside this scope.

The inventory and protected manifest are persisted before any mutation. Run the
independent close.py CASE SOURCE_REVISION afterward; it verifies every removed
path absent and every retained hash unchanged. Both options are PREPARED ONLY;
run each at most once and only when admission actually needs space.
