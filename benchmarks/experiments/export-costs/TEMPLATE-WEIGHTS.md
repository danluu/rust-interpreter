next token/folded template census therefore uses each function's previously
measured preparation/lowering intervals from the unannotated schema-1 history.
Require the exact artifact, indexed function name and pre/post-transform hashes
to match before applying those weights. Retain the current instrumented times
separately. Neither set is a performance comparison or a guaranteed cache saving.

Replay the same original/wrong/five-edit/restored history once per case with the
qualified schema-2 exporter. Preselect cycle 1 as the retained restoration
reference, matching the prior edit-5 source. Compare actual adjacent states.
