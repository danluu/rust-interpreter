all direct, indirect, persistent-register and frame tests. Reuse the adopted
exporter/wrapper exactly; only install the new VM under a distinct tool key.

artifacts/maps/code. They must reproduce all old words and PC ownership with
spilling unchanged, retain backend regions/operations and assertions, and account
for every removed byte through successor liveness. No JIT allocation or guest
execution is permitted in this diagnostic.

original case profiles: complete logical and backend per-PC counts must match
the standalone indirect VM. Entropy, guest memory, native Calls/Returns and
compiled function counts must match too; no new declines. Reconstruct all
published code maps. Only code words implementing the spill rule may differ.

primary with its frozen schedule and gates. If it fails, park this composition
and keep full/held-out histories unstarted. If it passes, qualify remaining
selection/prepared paths and run full original project guards before adoption.

qualification. No production changes are merged from an unqualified result.
