# Shared-template runtime qualification

First run the unchanged 121 native/reference/cache/strict-Cargo commands using
the new VM and the exact adopted exporter/wrapper. Require the closed workspace
build, at least635 Rust tests in each profile,14 declared ignored controls, and
the full Python suite. The default-off runtime must preserve the original,
helper-edited, invalid and restored fixture outcomes, including unreachable
type/borrow errors and rejection of an actual partially checked artifact. This
does not exercise template sharing: these single-entry commands are a regression
guard for the production integration, not proof of its new suite option.

Next exercise that option on retained, hash-bound original pgrust full-parser
artifacts. Reuse the closed native test inventory and assertion outcomes for
114 tests, including the deliberately wrong initial-lookahead source. For both
artifacts compare ordinary preparation with two workers, requested sharing with
one worker, and requested sharing with two workers. Preserve original outcomes
and effective limits. Require truthful default-off, inactive-one-worker and
active-two-worker receipts, including counters from failed guest tests. Record
actual restored-function counts and bytes plus retained storage. Zero actual
sharing is a mechanism failure, not a reason to rerun a successful suite.

The suite CLI must also reject fresh mode, interpreter mode, omitted resumable
calls, duplicate sharing flags and partial-validation input before guest
execution. A separate one-entry original rg-aot suite will check that two
requested workers still use the ordinary single-worker path. Do not synthesize
smaller benchmark workloads or weaken assertion/limit checks to obtain hits.

These stages qualify behavior and mechanism coverage, not project latency.
After their closure, freeze a changed-source parser primary with native,
adopted baseline, baseline duplicate and sharing candidate. Use the original
five valid edits, deliberately wrong edit, original anchor and restored anchor:
eight states times four modes,32 commands. Only five valid edited pairs enter
the gate. Require median paired wall ratio plus maximum absolute A/A deviation
below1, paired CPU ratio at most1, and CPU ratio plus its A/A envelope at most
1.05. A failed gate stops larger comparisons; no favorable subset or unchanged
rerun overrides it. Full parser histories and the other project regression
guards remain necessary for adoption. A one-worker workload can only establish
regression safety for this option, since it cannot share between workers.

All cache population, scalar preparation, locking, copying, validation and
reporting remain inside measured commands. Tool setup is recorded separately.
The original parser is pgrust gram_core; the old internal Nushell-parser label
is incorrect and must not be propagated. The primary choice follows saved
preparation costs before any candidate timing. It is conditional on actual
sharing coverage, not a prediction of a speedup.

Use the root benchmark lock with45-second admission and two Cargo/test workers.
Strict fixtures require12GiB initially and8GiB before each child; saved-artifact
suite qualification requires12GiB initially and8GiB per child. The primary will
declare its actual cache reservation before execution. Keep successful captures
if a later observer fails, preserve all terminal failures, and never control
another session's workload to obtain a lock or a quiet host.
