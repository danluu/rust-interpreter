# Scalar private transfer qualification

The candidate omits unread argument lanes and zero-result transfers, and uses
immutable successful-path counts where shortest and longest Return paths match.
All other counts remain dynamic. Budget admission still uses maximum_steps over
all paths. Original guards, failure replay and guest-visible accounting remain.

Qualification requires the independent 137-body metadata census, 23 focused
controls and 600 workspace passes/profile (13 ignored), 121 strict Cargo/cache
commands, six original profiles and the unchanged changed-source primary.
See PLAN.md for exact invariants, ownership and resource/timing gates.
