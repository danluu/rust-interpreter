# Attribute remaining native call cost

The indirect-call prototype and its successor-flush composition failed their
complete-command wall gates. Keep both results and the adopted runtime. Before
another implementation, join the closed typed continuation census to the saved
adopted protocol maps, sampled PCs and complete per-PC profiles.

Group native Call samples by the typed callee identity, and Return samples by
the executing function. Preserve duplicate display names as different IDs.
Reconcile every transition sample and all native Call/Return counts with the
existing receipts. Report each callee's frame size, registers, emitted bytes,
native call sites, logical operations and protocol sample categories. Rendered
opcode labels describe workload shape only; they establish no operand, alias,
initialization or inlining proof. Indirect/VM calls are not silently included in
direct native incoming counts. Function-wide operations are not per-call costs.

Use the existing two partial sampled windows and bound-entropy whole-test
profiles in their separate scopes. Do not interpret sample proportions or
static words multiplied by call counts as retired instructions or speedups.
This analysis runs no guests, builds no Rust code and publishes no JIT code.

Run focused join controls and the analysis under the shared benchmark lock,
with 45-second admission and 12 GiB free initially, retaining an 8 GiB floor.
Freeze all inputs and verify the prior closure. Keep the paused goal, two-worker
setting and ownership boundaries. Select any follow-up mechanism only after
reviewing this result and the already-completed frame/ABI experiments.
