# Execute the saved folded programs

The first complete-command token screen stopped at disk admission before any
build or execution. Use the three already transformed, exactly verified saved
programs to check the original token, folded-trie and pgrust assertions while
fresh Cargo caches cannot be admitted. This is a runtime diagnostic; adoption
still requires the frozen actual-edit screen and its guards.

Use the unchanged VM from suite-profiling-build-02, with prepared isolation,
resumable calls, persistent registers and the exact preceding suite limits.
Retain every entry in each original catalog. Re-run whole-artifact verification
before deriving the candidate catalog: only its artifact digest changes, because
the typed transform preserves all function IDs, entry IDs, names and layouts.
Bind both catalogs to the saved native and custom assertion receipts.

For each case, record a real entropy stream in one original-artifact execution.
Then run three pairs of original and folded artifacts, alternating mode order,
replaying exactly that stream. Use the existing fixture-qualified entropy
library only in these explicit VM children. Every replay must consume the tape
exactly, preserve its hash, pass every original native assertion, and match
guest peak memory per test. Instruction counts may change between artifacts;
they must remain identical across repeats of the same artifact. Record wall,
child CPU, instruction totals and JIT statistics as diagnostic observations.
Do not apply the end-to-end performance gate to runtime-only numbers.

There are three untimed verifications and 21 VM commands. No Cargo/rustc child,
source edit, code build, artifact copy or dependency cache is needed. New files
are catalogs, bounded entropy tapes, suite reports and raw records. Hold the
repository lock with a 45-second wait, require 4 GiB free before each child and
record available space. This is the reserve already specified in STORAGE.md;
the diagnostic creates only small evidence files. Preserve every failure and
stop on an assertion, entropy, identity or exact-artifact mismatch.
