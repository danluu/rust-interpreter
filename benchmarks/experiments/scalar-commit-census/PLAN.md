# Scalar Call commit census

The private frame ABI failed its complete edited-source primary (wall 0.994813,
A/A 0.016892). Keep that decision and inspect a different mechanism before
another runtime change. The adopted runtime remains the performance control.

Reconstruct every scalar body in the three closed private-ABI profiles from
its pinned original bytecode. Traverse the bounded acyclic CFG to find the
minimum/maximum instruction count reaching a successful Return. Exclude paths
ending only in Trap; retain both structural alternatives of every Switch and
assume each Assert can succeed. Different success lengths decline a constant.
Use original successful scalar PC counts to check each fixed count and count
zero-byte results, block visits and the associated private commit accesses.
Failed native attempts are outside this census; no hardware timing is inferred.

This observer changes no production code, runs no guest and publishes no
executable code. Its unit control includes unequal/equal Return paths, longer
fault-only paths, nonmonotonic edges and cycles. Compile it at the same source
root in the existing shared target with the usual lock, two workers and 14 GiB
(or 8 GiB plus twice target allocation) admission. Retain exact code/profile/
bytecode hashes, complete output and terminal receipts before deciding whether
fixed-success accounting and zero-result commit omission merit implementation.
