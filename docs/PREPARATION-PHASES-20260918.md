Next prototype bounded reusable register-fact storage for ordinary emission.
The current emitter allocates tree nodes for facts, definitions and live-ins
inside every region. A per-function dense workspace can avoid those lookups and
allocations; touched-entry clearing must prevent facts leaking between regions,
and sorted flush order must preserve generated bytes. This is a hypothesis,
not an attributed allocation cost or measured gain. Large/unsupported sizes and
optional workspace allocation failure retain the existing sparse representation.
