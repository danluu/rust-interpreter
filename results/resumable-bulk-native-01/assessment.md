# Broader native differential qualification

Experimental tool `78e60cdd`, runtime source `001065a`, passes the full existing
validator in default and leaf-inlined modes with resumable Calls/Returns and
persistent registers explicitly enabled. Both supervisor and controller ended
with exit 0. The staged validator preserves every original assertion AST.

The 47,004 recorded commands comprise 22,238 JIT invocations, 22,238 interpreter
invocations, two default-engine corrupt-artifact rejections, 408 exports,
236 native builds and 1,882 native program/test executions. These include
intentional rejection checks; they are command categories, not unique test cases.

The selected immutable VM, flags, counters, compiler inputs, complete command
archives and their hashes are verified in [summary.json](summary.json). Run with
`scripts/qualify_native_execution.py --run-id NEW_ID --tool-key FULL_KEY
--jit-resumable-calls --jit-persistent-registers` through the experiment supervisor.
The driver takes the benchmark lock and runs both modes serially.

This establishes execution/rejection equivalence for the existing validator.
Its explicit partial-checking option tests do not enable partial checking in
the production workflow. It adds no OS/FFI, thread or unwind support and does
not change either failed token performance gate.
