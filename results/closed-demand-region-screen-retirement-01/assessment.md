# Retire only closed demand-screen compiler intermediates

Removed 3,147 nonexecutable compiler intermediates totaling 1,912,206,947 logical
bytes from the five exact caches owned by the completed failed token screen.
The source pin, restored source, all forty outcomes, snapshots and terminal
receipts were verified before deletion. Shared/invocation locks, process checks,
open-file checks and per-file identity checks constrained the operation.

All 2,531 protected hashes remain unchanged; the closure verifies every removed
path is absent. Executables, bytecode/catalog snapshots and raw evidence remain.
The shared build target, installed tools, private and peer caches were excluded.
Free space rose from 13,931,061,248 to 15,512,150,016 bytes during the operation;
concurrent host activity means that change is not an exact physical-byte census.
