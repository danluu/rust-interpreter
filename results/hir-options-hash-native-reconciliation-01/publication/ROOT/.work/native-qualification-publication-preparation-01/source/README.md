# Standalone native qualification evidence

This is an unrun publication source proposal. The original A-owned source,
receipts, fixtures and provider bytes are immutable inputs. No compiler or
native program runs during publication.

The approved scope successor adds four exact native03 generated files to the
previous scope: its 51,224-byte stock wrapper, 2,090-byte derived source,
13-byte wrong-role source and 66-byte restored fixture. These are qualified
output artifacts; no E2/D2/B3/SDK/std provider library is copied. The older
unqualified wrappers remain explicitly outside the payload.

The archive contains all three failed native histories (5, 6 and 20 commands),
the separate zero-command reconciliation, its independent audit, rejected
unrun stock controls, and all passed stock4/loader9/parser11 controls. It
includes every receipt and raw stream, all 376 original gzip proof files
(67 + 130 + 179), all 89 physical files for the 125 logical reconciliation
delta inputs, and the four retained native program executions. The failed
numeric-PID audit and corrected PID-aware audit are both preserved.

The previously committed B308 archive is an explicit prerequisite reference.
Every new native/reconciliation qualification proof is byte-bearing here;
the current provider payloads stay in their separately guarded namespaces.

The unchanged B308 streaming engine uses SHA/size archive aliases, never
filesystem hardlinks. It reads every logical archive member back and consumes
the complete outer gzip stream through EOF. The history guard additionally
checks every inner original gzip blob through logical hash and EOF.

Limits remain 2,048 members, 64 MiB per file, 512 MiB logical members,
384 MiB unique payload, 192 MiB compressed archive and 416 MiB expanded tar.
Admission requires the canonical lock and 9 GiB plus 416 MiB free; every
bounded read/write checks the unchanged 9 GiB live threshold.

Fresh publication paths are ROOT/results/hir-options-hash-native-reconciliation-01
and ROOT/experiments/native-qualification-source-01. The latter contains 58
exact source copies (512,816 bytes) plus their provenance map. The archive
controller's WORK is outside candidate evidence prefixes. No existing file
is removed or replaced. Original native03 remains failed; the separate
read-only receipt qualifies its 20 saved commands. This is correctness
evidence and makes no performance claim.
