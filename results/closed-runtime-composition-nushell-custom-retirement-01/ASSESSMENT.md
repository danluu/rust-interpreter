# Completed Nushell custom caches retired

Only the three exact completed custom compiler namespaces from the closed
132-command Nushell history were eligible. The controller verified the complete
726-command project closure, every retained case artifact and original source,
then acquired each invocation lock and checked for open files.

It removed 33,924 nonexecutable compiler intermediates totaling 12,730,891,710
logical bytes. Observed free space rose from 23,032,410,112 to 31,306,891,264
bytes during the operation; logical bytes and physical reclamation differ.
All 20,095 protected hashes remain unchanged. The later closure confirms every
removed path is absent and every protected file still matches.

Executables, bytecode/catalogs, source, raw measurement evidence, native/parser
caches, installed tools, the shared build target, private and peer caches were
preserved. No process was signaled. The standalone close wait timed out before
audit; a later batched audit finished normally. Cleanup does not imply runtime
adoption or parser-performance qualification, and must not be repeated.
