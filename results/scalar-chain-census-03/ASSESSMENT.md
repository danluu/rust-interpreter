# Defer confined scalar call chains after exact sample attribution

All five commands pass: four Rust controls per profile, one typed original
artifact census, two existing Python attribution controls and the evidence join.
The controls include five reference-interpreter values and two expected entry-
width rejections per profile. The prior compile-path and fixture failures remain
separately closed. No original-project guest or executable publication occurred.

The census admits 478 existing leaves and 57 additional bounded call chains.
None of those chains owns a Call/Return sample in either closed token capture
(409/440 transition samples; 1561/1231 generated samples). Every typed Function
hash and direct-call target matches the closed original attribution.

This is structural admission only: parent scalar graphs, logical frame addresses,
resource peaks, original-PC accounting and fault replay remain unimplemented.
The narrow scope does not justify that implementation now. Most sampled rejected
chains lead to external effects, pointer reads, byte comparisons or larger bodies.
Relaxing those proofs would be a separate design, not a valid inferred gain.

The next bounded investigation is value retention inside already guarded external
ranges. The earlier guarded-value census required an original register fact still
to hold the value and found almost no reuse. A small private native register cache
could retain complete payloads after those facts expire. It must keep all writes
immediate, invalidate overlapping/unknown writes, use the existing disjoint proof,
and account for capture cost before any native implementation. This is distinct
from reintroducing speculative path checks or the parked ordinary-local cache.
