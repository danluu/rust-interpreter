# Runtime prerequisite adapter controls

Source-only proposal for eleven synthetic runtime02 Reader/factory controls. No preparation, imports, tests, provider probes or runtime workloads have run through this harness.

The child loads only test_prerequisite_successor and its two tested local modules, prerequisites.py and imports.py, from the exact runtime-installation-02 source. The fixture is entirely in memory; it mocks process and file APIs and never loads a hash controller or the original runtime providers. source-bindings.json is retained as source context and the preparer checks its exact digest plus the three reviewed tested-source hashes.

The original runtime01 Mach-O, monitor and controller qualification remains separate and unchanged. These eleven controls qualify only the successor Reader/factory behavior and exact original module routes; they make no claim of runtime installation, native workload qualification or performance.

The harness is a narrow successor of the passed ROOT prerequisite-controls04 harness: canonical lock wait 600 seconds, fresh 16 GiB admission, 9 GiB live stop and 8 GiB floor, one child, 120-second alarm, 60 CPU seconds, 256 KiB per file, 256 writable names, 2,048 directory names and 2 MiB retained stage output. Child process/network/signal calls are forbidden.

The dispatcher and independent audit drafts are under O/.work and have no concrete launch/freeze association until a separately reviewed preparation. No actual launch is authorized by this source proposal.
