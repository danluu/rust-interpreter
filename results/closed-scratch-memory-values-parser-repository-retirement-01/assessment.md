# Closed parser compiler-cache retirement

Retired 967 nonexecutable compiler intermediates (247,815,120 logical bytes)
from the four exact caches of the completed repository-profile parser history.
All 10,621 protected hashes remain unchanged, and every removed path is absent.
The original 88-command outcomes, source restoration, artifact snapshots,
historical source bindings, invocation locks and open-file checks were verified.

Recorded free space rose from 15,019,356,160 to 15,265,067,008 bytes. Concurrent
host activity means this difference is not an exact physical reclaim figure.
Shared build targets, installed tools, private caches and peer work were excluded.
