# Twenty legacy native caches archived and verified

The reviewed targets complete and verify: 128,089 paths, 14,667,567,702 original
payload bytes and 3,587,697,833 archive bytes. Every payload was decoded and hashed
before retirement. All 1,275 distinct evidence hashes remain unchanged, including
original completion records, logs, report failures and archived harnesses.

The catalog covers seven public Nushell, Ruff and pgrust histories and twenty
LLVM/Cranelift cache targets. No old backend was executed by this maintenance.
Private caches, function caches, sources and installed tools were not selected.
The oldest pilot's repeated A/B format is preserved as recorded; this report
makes no new compilation-performance claim.

The [reviewed inventory](inventory-review.json) was committed in `28da88d` before
application. See the [complete receipt](summary.json). The archive registry now
contains 205 entries. Shared-volume free-space changes are not attributed solely
to the difference between original and compressed logical bytes.
