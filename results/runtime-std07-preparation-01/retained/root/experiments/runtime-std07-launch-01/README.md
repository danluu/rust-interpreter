# Ordinary std07 launch observer (source only)

`launch.py` consumes the reviewed std07 packet only after the exact binder02 transport record reports success and actual child closure. All actual launch, inputs and binding-execution hashes are external command arguments and remain unbound. No launch, compiler, std command, provider walk or runtime import was performed while preparing this source.

The direct command is the unchanged R `scripts/supervise_experiment.py` with the exact binder-generated argv, complete environment and cwd. Its detached supervisor invokes the existing std07 `prepare.py`; the ordinary CLI acquires canonical then std locks. This observer acquires neither lock and preserves the 16 GiB entry, 9 GiB active-stop and 8 GiB floor contract. The original seven ordinary CLI labels and return codes remain in the authenticated packet/controller; this observer does not reimplement those commands.

The bounded observation comes from the current runtime07 launcher: `require`, `sha`, and `read` are AST-identical. Its runtime-specific source/controls admission is replaced with the already closed std binder/output associations. The wrapper wait has an immediate 30-second deadline and runs even if first record publication fails. A separate 1,800-second supervisor receipt observation uses the same two-second polling interval. Timeout, wrapper failure, or malformed observation retains evidence and raises without signal or retry. It does not restore or delete anything.

The record identifies this observer and its actual direct wrapper child, preserves the original supervisor handoff including identity text, and records the supervisor/controller IDs from the associated terminal. The supervisor's `finished` receipt attests that its controller was waited. The detached supervisor itself is not reaped by this observer; `detached_supervisor_os_closure_observed` stays false. Raw supervisor logs copied at terminal observation are labelled current observations. No status is treated as a saved std qualification or downstream application/performance proof.

Only six selected packet/binding/source files plus terminal/supervisor metadata and raw logs are retained in the fresh launcher directory. Provider/std output trees remain outside this observer. Source and packet associations are rechecked immediately before spawn and after terminal observation. The unchanged std prepare/CLI perform their complete existing source/configuration/executor/runtime checks.

The old std01 launch record is a closed historical example of the same ordinary wrapper argv/environment; it recorded only that short wrapper's closure. No corresponding old launcher source is claimed. The stronger supervisor observation is explicitly derived from runtime07 source, with its full diff retained next to this file. The original std01 and all current tested/binder/transport sources are unchanged.
