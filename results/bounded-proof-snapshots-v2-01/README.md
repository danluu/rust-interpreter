# Bounded proof snapshots v2

The reusable lossless snapshot helper passed seven original controls and fifteen reference-reuse controls in the original A worktree. Callers must separately bind a closed audited predecessor and an already-counted evidence root; reuse only reduces new physical writes. Total logical and compressed limits remain enforced.

Published source copies are byte-identical to the A originals. Historical controls contain their original paths and are not a ROOT execution recipe.
