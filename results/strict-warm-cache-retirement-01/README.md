# Completed negative experiment cache retirement

After publication and validation of the negative retention and native-host MIR screens, their two task-owned generated cache directories were removed to make room for compiler bootstrap. Both experiments were complete; no further runs in those cache histories are planned.

The cleanup checked ownership stamps, completed command receipts, all archived member hashes, and retained artifact hashes. Read-only process and open-file checks found no use of either cache. The original source, command reports, logs, receipts, source snapshots, copied artifacts, installed tools and published evidence remain available. No other cache or process was changed.

[summary.json](summary.json) records the exact paths, timestamps, ownership, evidence archive identities and full local inventory receipt hash. The original experiment assessments describe retention at publication time; this record documents the subsequent cache removal. It does not change their measurements or conclusions.
