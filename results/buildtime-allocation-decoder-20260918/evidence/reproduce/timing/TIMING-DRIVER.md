Each process imports the actual source module once, then times exactly one chosen public API call. `validate` preloads bounded immutable trace bytes and verifies their size/hash outside both component clocks; only `validate_trace(data, artifact_sha256)` is timed. `selected` does not preload file contents: the actual `selected_trace(artifact)` file reads, identity checks, hashes, and validation are inside both clocks. Metadata/path checks precede timing. Full-process metrics include those checks, preload where applicable, module import, and reporting.

After both clocks stop, the driver compares the integer count or the complete selected receipt against the qualified metadata. It reports the unmodified result, complete expected receipt, exact exception class/module/message and explicit cause chain, JSONDecodeError fields or lossless UnicodeDecodeError byte fields, module file/cache inventory, and Python/cache identity. Parity-phase calls are correctness evidence and never adoption samples; only the fixed measured phase contributes performance samples.
