An independently rebuilt artifact inspector passes an identical-artifact control. Token original/restored bytecode differs in 1,619 functions: every changed instruction is an immediate, with unchanged function headers and instruction counts. Readonly data grows by 192 bytes; static initializers also change. The two production edits with low exact-output reuse change 1,999 and 2,008 functions, but only one and five functions respectively have non-immediate instruction changes.

This is consistent with embedded addresses propagating data-layout changes through otherwise stable code. Numeric immediates do not identify pointers, so this inspection does not normalize them or prove equivalent allocation identities. The next experiment will mark relocation sites where the typed exporter creates them, before considering reuse.
