# Closed parser compiler-cache retirement

Removed 13,955 nonexecutable compiler intermediates from the five exact caches
of the completed 40-command indexed-switch parser primary. Its performance
gate remains failed; no command was repeated. Source restoration, original test
outcomes, process identities, invocation locks and open-file checks passed.

The inventory contains 2,669,113,785 logical bytes. Observed free space increased
from 12,813,144,064 to 15,275,032,576 bytes; logical size is not reported as
recovered disk space. All 10,376 protected hashes remained unchanged. Executables,
bytecode/catalog snapshots, raw evidence, installed tools, the shared build target
and all peer work were preserved. The closure reverified every removal and every
protected hash.
